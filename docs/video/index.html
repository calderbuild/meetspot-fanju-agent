所以我做了 MeetSpot 饭局 Agent
第一步，谁来吃
每个人说一句自己的要求，大白话就行
第二步，去哪吃
它先把每个人的话整理成条件，列出来
大家对一眼
然后在大家中间找附近的店，不合适的直接划掉
你看，每一家都写着是谁的哪条要求
比如小张吃素，这家的招牌菜是烤鸭
留下来的店，我标的是按品类初筛
还没核实
第三步，点什么
到店拍一下菜单，它只读照片上真有的菜和价格
读错了直接改就行
没在店里，也能用一张示例菜单试试
最后出一张点菜单
每道菜写着谁能吃，总价按菜单价格算
人均六十四，没超预算
这里模型只干两件事，听懂人话，读菜单
规则都是代码一条一条查的，所以每次划掉
都有理由
过敏它只做提示，点菜单上一直写着
过敏原请向店员确认
